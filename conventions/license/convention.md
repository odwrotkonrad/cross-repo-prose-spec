# License Convention

Every public repo carries `LICENSE` at the root: unmodified MIT, rendered from `prose/shared/license/LICENSE` at the repo's pinned prose version. Never edited per repo. Change the canonical source, regen propagates it.

- Copyright line: `Copyright (c) 2026 Konrad Odwrót (Konrad Zagozda)`, same everywhere.
- Forges (GitLab, GitHub mirror) detect the license from the file. Nothing configured forge-side.
